# Stanley Liang — Portfolio

[Stanley Liang](https://sliang07.github.io) — Senior Full-Stack Engineer, Seattle, WA.

## About this site
- Modern, fully static one-page site — plain HTML/CSS/vanilla JS, no frameworks, no build step
- Dark & clean design system (GitHub/Linear-inspired): charcoal background, teal accent, Inter + JetBrains Mono
- Started as [Prologue by HTML5 UP](https://html5up.net) (CCA 3.0, see `LICENSE.txt`), then fully redesigned

## Sections
- **Hero** — headline, availability badge, CTAs, social icons
- **About** — summary + highlight stats
- **Experience** — MyAtOnce, Coding Dojo, JCPenney, BananaGo (timeline)
- **Projects** — MCP Photoshop Server (open source, featured) + PokeMart, Price Compare, Doctor's App
- **Skills** — grouped pills
- **Education / Contact** — background + big email CTA (phone available upon request)

## Updating
- Content: `index.html`
- Design tokens (colors, fonts, spacing): top of `assets/css/main.css`
- Interactions (mobile nav, scroll-spy, reveal-on-scroll): `assets/js/main.js`

Commit and push to `main`; GitHub Pages (Settings → Pages → Deploy from a branch, `main`, `/` root) picks up changes automatically.
